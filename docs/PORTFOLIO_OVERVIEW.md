# 근거있어 | 포트폴리오 안내

## 해결하려는 문제
광고의 주장과 제품의 공식 기능성 범위를 나눠 확인하기 어렵습니다.
건강기능식품·기능성화장품 광고를 공식 데이터와 대조하고, 주장별 판정과 사유·원문·출처·규칙 버전을 근거영수증으로 제공합니다.

## 구현과 역할
개인 프로젝트로 공식 데이터 감사, 원문 파서, 주장 추출, 규칙 판정, 영수증, FastAPI와 로컬 화면을 구현했습니다.
판정은 명시적 Python 규칙을 사용합니다. 제품·공식 문구·규칙이 불확실하거나 광고를 끝까지 읽지 못하면 확인을 보류합니다.
AI 도구는 개발·검토·평가 라벨 작성에 활용했으며, AI 라벨을 사람 정답으로 취급하지 않습니다.

## 판단과 검증 근거
- [README](../README.md): 현재 기능, 동결 평가 결과, 낮은 확인됨 재현율을 함께 공개했습니다.
- [평가·검토 기록](evidence/): 새 평가에서 기준을 못 맞춘 규칙을 철회한 근거를 남겼습니다.
- [동결 평가세트](../data/eval/): 규칙 변경의 효과와 오인 승인 위험을 구분해 확인합니다.
- [엔진 코드](../src/claimledger/): 데이터 해석·판정·영수증을 구분한 구조를 볼 수 있습니다.

## 확인된 한계
자유로운 광고 문장은 검증 불가로 남는 경우가 많습니다.
평가 문장과 라벨은 AI 기반이며 사람·전문가 정확도를 입증하지 않습니다.
현재 범위는 공식 제품·기능성 정보 대조이며, 논문 근거 검증과 OCR·URL 수집은 구현하지 않았습니다.
배포 서비스가 아니며 Docker 빌드·실행도 README 기준 미검증입니다.
이번 정리는 기존 공개 자료를 안내하는 문서 작업이며 평가를 다시 실행한 결과가 아닙니다.

실행 방법과 데이터 조건은 [README](../README.md)를 확인해 주세요.
