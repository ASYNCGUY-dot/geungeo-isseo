# 핵심 원료 3종 MVP 수직 슬라이스 실행 계획

> 2026-09-27 사용자 결정: 사람 검토는 생략하고 A를 AI 대리 라벨로 닫은 뒤, 확장 원료 선정(B·C)보다
> 핵심 MVP를 먼저 만든다. 발표 2026-10-12, 설명문서·코드 제출 10-10.

**Goal:** 광고 문구(텍스트)와 사용자가 확정한 C003 제품으로 주장별 근거영수증을 만드는 흐름을
루테인·지아잔틴, 오메가3, 프로바이오틱스에 대해 끝까지 동작시킨다. `확인됨` 오인 승인 0건을 최우선으로 한다.

**Architecture:** 기존 Phase 1(제품 검색·사용자 확정·원료 매핑)을 재사용한다. 새 모듈은
공식 기능성 파서 v2, 광고 주장 추출 v1, 주장별 판정 v1, 근거영수증 v1과 CLI다.
판정은 결정론적 규칙만 내리고, LLM은 이 슬라이스에서 쓰지 않는다.
API·웹 화면은 수직 슬라이스가 CLI로 검증된 뒤 붙인다.

**Tech Stack:** Python 3.12, Pydantic v2, pytest. 새 의존성 없음(API 단계에서 FastAPI 추가 여부를 사용자에게 확인).

  - 막는 이유는 `UNPARSED_OFFICIAL_FUNCTION`(거의 전부)과 `AMBIGUOUS_INGREDIENT_MAPPING`(약 40%)이다.
  - 원인: v1 파서가 정확히 일치하는 6문구만 인식하고, 제품 전체 문구가 해석돼야 READY가 된다.
- 기능성 원문에서 대상 원료명이 붙은 표시의 비율:
  - `[원료명]` 또는 `원료명 :` 형태가 루테인 934/1,352(69%), 오메가3 2,073/2,704(77%), 프로바이오틱스 3,360/5,477(61%).
  - 나머지는 원료명 없는 나열이다.
- 공식 문구는 규칙적이다. 변형은 구분자(`·`, `･`, `․`, `, `), 띄어쓰기(`눈건강`/`눈 건강`, `혈행개선`), 어미(`도움을 줄 수 있음`/`도움을 줌`, 끝 마침표) 정도다.
- 같은 기능 문구를 다른 원료가 쓰는 경우가 있다.
  - `기억력 개선`·`혈행 개선`은 은행잎 추출물, `배변활동 원활`·`장내 유익균 증식`은 식이섬유·올리고당도 쓴다.
  - 따라서 원료명 귀속 없이 `확인됨`을 내지 않는다(A 게이트에서 확인된 오인 경로와 같다).

제외(이 슬라이스): OCR, URL 수집, LLM 주장 추출, 논문 RAG, 로그인·저장, 확장 원료, 개인 맞춤 판단.

## 판정 규칙 v1 (`claim-verdict-v1`)

순서대로 fail-closed로 적용한다. 앞 단계에서 멈추면 뒤 단계로 가지 않는다.

1. 제품이 사용자 확정되지 않았으면 `unverifiable` / `PRODUCT_IDENTITY_UNCONFIRMED`.
2. 주장이 사용자 확인되지 않았으면 `unverifiable` / `CLAIM_UNCONFIRMED`.
3. 주장 표현 강도가 `treatment_prevention`(치료·예방·완치 등)이면 `mismatch` / `DISEASE_CLAIM_BEYOND_FUNCTIONAL_SCOPE`.
   - 건강기능식품의 공식 기능성 문구는 치료·예방 표현을 담지 않으므로, 공식 인정 범위를 벗어난다는 사실만 말한다. 법적 판단은 하지 않는다.
4. 주장 효과가 규칙 어휘에 없으면 `unverifiable` / `CLAIM_OUTSIDE_RULE_SCOPE`.
5. 제품 공식 기능성에서 해당 효과를 **대상 원료명 표시 블록 안에서** 찾는다.
   - 있으면 6단계로 간다.
   - 효과 문구가 원문 어디에도 없으면(공백 무시 대조) `mismatch` / `EFFECT_NOT_IN_OFFICIAL_FUNCTIONS`.
   - 원문에 있지만 대상 원료에 귀속되지 않으면(원료명 없음, 다른 원료 블록) `unverifiable` / `OFFICIAL_ATTRIBUTION_AMBIGUOUS`.
6. 광고 강도가 공식 강도를 넘으면 `mismatch` / `EXPRESSION_STRENGTH_EXCEEDS_OFFICIAL`.
   - 공식 문구는 모두 '도움을 줄 수 있음(줌)'으로 끝나므로 공식 강도는 `support`다.
   - 광고가 '개선됩니다·좋아집니다'처럼 단정하면 `improvement`로 보고 공식 강도를 넘는다고 판정한다.
7. 모두 통과하면 `confirmed` / `MATCHES_OFFICIAL_FUNCTION`.

표현 강도 순서는 설계서대로 `possibility < support < improvement < guarantee < treatment_prevention`이며, 더 강한 표현을 약하게 완화하지 않는다.
판정은 '공식 인정 범위와의 일치'만 말한다. 효과·안전·적법성을 보장하지 않는다.

## 규칙 어휘 v1

공식 효과 키(원료군별):
- 루테인: `macular_pigment_eye_health` — 황반색소밀도 유지로 눈 건강.
- 오메가3: `blood_triglyceride`, `blood_circulation`, `memory`, `dry_eye_eye_health`.
- 프로바이오틱스: `probiotic_growth_harmful_inhibition`, `bowel_movement`, `gut_health`.

광고 쪽 표현은 공식 효과 키로 사상할 때만 쓴다. 다음은 효과 키로 사상하지 않는다(= 4단계 `unverifiable`).
- 시력 개선, 노안, 피로 회복, 면역, 다이어트 등 어휘에 없는 표현.
- 명시적 질병·치료·예방 표현은 3단계에서 강도로 먼저 걸린다.

어휘에 없는 효과를 `mismatch`로 몰지 않는다. 오판 방향이 오인 승인은 아니지만 정확도를 해친다.
