## 한계 — 이 수치를 어떻게 읽어야 하는가

- **작고 순환적인 표본이다.** 광고 문장·기대 판정·규칙을 같은 AI 개발자가 만들었다. 독립 평가가 아니다.
- **개발 중 조정에 쓰였다.** LZ-06('사라집니다')·PB-05('높여줍니다')가 처음에 주장으로 뽑히지 않아
  표현 강도 단서를 테스트 먼저 방식으로 추가했다. 그 결과 29/30이 나왔으므로 낙관적인 수치다.
- 설계서의 동결 평가세트(100건, 사람 라벨)는 아직 없다. 서비스 정확도나 발표용 성능 수치로 인용하지 않는다.
- 실제 광고는 문장이 길고 여러 주장이 섞이며 이미지 속 글자가 많다. 이 사례들은 한 문장짜리 텍스트다.
- `근거 부족`·`직접 반박됨`은 과학 근거 층이 없어 만들지 않는다.

## 웹 화면·API (Task 6)

새 의존성은 사용자 확인("설치하고 다음 단계 진행해줘") 후 설치했다: FastAPI 0.141.1, uvicorn 0.54.0(starlette 1.7.0 동반).
**운영성**을 위한 추가다. 같은 결정 엔진을 브라우저에서 단계별 확인(주장 확인 → 제품 확정 → 판정)으로 쓰게 한다.
판정은 서버 상태에서 결정 엔진이 만든다. 클라이언트는 판정을 보낼 수 없다.

- API: `src/claimledger/api.py`. 오류는 `{"error": {code, message, retryable, user_action, analysis_id, trace_id}}` 형식이다.
  제품 미확정 상태에서 판정을 요청하면 409 `PRODUCT_IDENTITY_UNCONFIRMED`로 거부한다.
  - 분석은 메모리에만 두며 서버를 끄면 사라진다.
- 화면: `src/claimledger/web/index.html`(외부 스크립트 없음).
  - 체크하지 않은 주장은 `검증 불가`로 남는다.
  - 제품은 검색 후보의 공식 기능성 원문을 보고 사용자가 직접 확정한다. 자동 확정은 없다.
- 실행:

  ```powershell
  .venv\Scripts\python.exe scripts\serve_api.py --source-retrieved-at 2026-08-27T12:42:29.050550+00:00 --port 8000
  ```

  브라우저에서 `http://127.0.0.1:8000/`을 연다. 기본 바인딩은 `127.0.0.1`이다.
