# AI 선행 검토 기록 — 2026-09-16

이 문서는 9월 16일 중간 이력이다. 현재 상태와 완료/미완료 구분은
[9월 23일 인계](FUNCTIONAL_ROLE_AI_REVIEW_2026-09-23.md)를 우선한다.

## 승인과 현재 범위

사용자는 2026-09-14 “그 방식으로 다음 단계 넘어가줘”로 남은 269건의 AI 선행 검토를 승인했다.
2026-09-16 “이어서 진행해줘” 요청에 따라 사용량 제한으로 중단된 검토를 재개했다.

이 승인은 AI 참고 판정 작성에 한정된다. 기존 사람용 라벨 CSV에 자동 이관하거나
서비스 확정 판정·독립 사람 평가·전문가 검증으로 취급하지 않는다.
현재 검토 기준은 [AI 검토 지침](../AI_ROLE_REVIEW_RUBRIC.md),
실행 기록은 [실행 계획](../superpowers/plans/2026-09-14-ai-role-review.md)을 따른다.

## 입력과 재개 이력

- 입력은 기존 검토팩의 실제 미작성 키 269개다. 밀크씨슬 50, 비타민D 55, 홍삼 54,
  코엔자임Q10 55, 마그네슘 55건이다.
- 원료군·신고번호와 제품 원문 6필드만 제공했다. 기계 판정·표본 층·이전 AI 답은 입력에서 제외했다.
- 2026-09-14 입력 감사: 269개 키와 1,614개 원문 필드가 C003 스냅샷과 일치했다.
- 2026-09-16 재개 시 네 출력 파일에 149개 행이 있었다. 원료군별 작성 수는
  밀크씨슬 50, 홍삼 54, 비타민D 22, 코엔자임Q10 23이다. 마그네슘 파일은 없었다.
- 저장된 149행은 키·인용 대조에서 오류가 없었다. 이를 전체 의미 검토 완료로 확대하지 않았다.
- 네 사본을 `audit/pre-resume-2026-09-16/`에 바이트 동일하게 보존한 뒤,
  비타민D 33, 코엔자임Q10 32, 마그네슘 55건의 미작성분을 재개했다.
- 원래의 첫 배치 5건, 두 미해결 이견, 기존 검토팩·규칙·원문은 변경하지 않는다.

검토 원본은 2026-08-27 C003 스냅샷이며, 규칙은 2026-09-14 재확인본이다.
이번 작업은 웹 최신성 재조사나 C003 재수집이 아니다.

## 산출물과 출처 경계

로컬 루트: `build/functional-role-ai-review-2026-09-14/`.
폴더 날짜는 시작일이고 실제 결과의 검토 시각은 각 파일에 별도로 기록한다.

- `inputs/{group}.json`: 기계 결과가 제거된 원문.
- `reviews/{group}.json`: AI 유형·검토자·실제 시각·행별 후보 판정·인용·이유.
- `audit/provenance.json`: 승인 문구, 보호 파일 13개와 입력 파일 해시.
- `audit/worker-assignments.json`: 실제 AI 작업 식별자.
- `audit/resume-2026-09-16.json`: 중단·재개 시점의 작성/미작성 수.
- `audit/input-validation.json`: 원본 키·필드 일치 검사.
- `progress.md`: 재개용 작업 이력.

`supported_candidate`는 원문과 제한된 규칙상 기능성 역할을 지지하는 AI 후보다.
제품 효능·안전·광고 적법성 확인이 아니다. `contextual`은 문맥 추론이며
`explicit`과 별도로 집계한다. `uncertain`은 검토했지만 근거가 부족하거나 귀속이 모호한 상태다.

AI 검토의 정확한 모델명·완전한 블라인드 독립성·전문 자격은 주장하지 않는다.
검토자에게 기계 결과를 제공하지 않았다는 입력 설계와 독립 사람 정답의 확보는 서로 다르다.
같은 계열 AI의 추가 검토도 사람 평가를 대체하지 않는다.

## 검증 진행 상태

269건 결과 작성과 후속 의미 감사는 진행 중이다. 결과 파일을 읽고 키·스키마·인용·시각·보호 해시를
전수 검증한 뒤 최종 수치를 기록한다. 미작성 행을 자동으로 불확실로 채우지 않는다.

2026-09-16 기존 역할 pack의 실제 validator는 `PENDING`, 유효 6, 대기 269, 이슈 0,
exit 2, summary null을 반환했다. 유효 6은 이전 승인 AI 5 + 상속 매핑 오류 제외 1이다.
A 적격성 미측정, 광고 근거 B `NOT_MEASURED`, 추천 C `BLOCKED`, `finalized=false`를 유지한다.
이 수량과 별도 AI 검토 작성 수를 혼동하지 않는다.
