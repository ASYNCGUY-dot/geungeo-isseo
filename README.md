# 근거있어

**건강광고, 말보다 근거부터.**

근거있어는 건강기능식품 광고가 한 주장을 **공식 제품 정보와 선별된 과학적 근거에
대조하여, 확인된 범위와 확인할 수 없는 범위를 주장별 근거영수증으로 보여주는 정확도
우선 검수 서비스**입니다. 결정적 검증 로직과 파이썬 패키지는 내부 엔진명
`ClaimLedger`와 `claimledger`를 유지합니다.

## 현재 상태

**귀속 범위·정확도 개선 4단계 중 1·2단계를 마쳤습니다.** 1단계 독립 AI 재검토에서 나온 P1 2건을 모두 막았습니다.
헤더는 원료명 사전으로, 본문은 공식 문장 사전으로 검사해 처음 보는 주석이 있으면 제품 전체를 보류합니다.
동시에 정상 공식 표기를 더 읽어 판정 가능한 제품이 늘었습니다. 2단계 독립 AI 재검토에서 가짜 `확인됨`은 0건이었고,
경미한 문제 2건은 v2.6에서 고쳤습니다. 헤더 아래 이어 쓴 다른 원료의 공식 문장까지 헤더 원료로 보던 한계(P2)는
원재료에 그 원료가 있고 문장이 글자 그대로 같을 때 보류하는 좁은 규칙으로 막았습니다(claim-verdict-v1.2, 실제 C003 보류 0개).
3단계는 고시형 원료 93개의 공식 기능성 대응표를 만든 상태이고, 개별인정형 목록(식품안전나라 `I-0040`)은 활용신청을 기다립니다
([대응표 기록](docs/evidence/CARRIER_TABLE_2026-09-30.md)). 현재 테스트 통과를 자동 승인·출시 허가로 해석하지 않습니다.

## 목표 MVP 경계 (현재 미구현 기능 포함)

아래는 최종 MVP의 목표이며 현재 지원 기능 목록이 아닙니다. 실제 구현 상태는 위의
`현재 상태`와 [코덱스 핸드오프](docs/CODEX_HANDOFF.md)를 기준으로 판단합니다.

MVP가 하는 일:

- 사용자가 광고 이미지 또는 텍스트를 입력한다.
- AI가 광고 문구에서 검증 가능한 주장을 원자 단위로 추출한다.
- 사용자가 제품 후보를 직접 선택하여 제품 신원을 확정한다.
- 공식 제품 정보, 공식 기능성 문구, 선별된 과학적 근거를 대조한다.
- 규칙 엔진이 `확인됨`, `근거 불일치`, `근거 부족`, `검증 불가`, `직접 반박됨` 중 하나를 출력한다.
- 모든 결과에 출처, 기준일, 적용 규칙, 불확실성을 함께 표시한다.

MVP가 하지 않는 일:

- 개인에게 효과가 있다고 보장
- 개인별 복용 안전성·의약품 상호작용 판정
- 질병 진단·치료·예방 조언
- 제품 실물의 함량·순도·오염 여부 판정
- 민간 서비스가 공식 광고 심의나 법적 판단을 대체한다고 주장
